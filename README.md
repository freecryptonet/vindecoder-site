# vindecoder.site

Free US VIN decoder — decode any US-market VIN and get NHTSA recalls, complaints, safety ratings, investigations and manufacturer data in one place. No ads, no login.

🔗 **Live:** https://vindecoder.site

## What it does
- Full VIN decode via the NHTSA vPIC database
- Open recalls, complaints, crash-test safety ratings and investigations
- US-market focused (NHTSA data is US-only)
- Fast repeat lookups via a MariaDB cache layer

## Stack
Next.js · TypeScript · MariaDB · NHTSA public APIs · deployed on a Linux VPS

Designed, built, and maintained by me.
